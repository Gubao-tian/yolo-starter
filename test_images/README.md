# 测试图片集

用于演示"上传照片自动识别"的真实图片（来自 COCO 公开数据集，非合成图）。

## 快速使用

1. 启动服务：双击 `webapp\启动识别.bat`，或运行 `.\.venv\Scripts\python.exe webapp\app.py`
2. 打开 `http://127.0.0.1:5000`
3. 页面下半部分有「没有照片？试试这些示例图」——**点任意一张即自动识别**，无需手动上传

也可以手动把 `test_images/selected/` 里的照片拖进上传框。

## 全物体提取模式（YOLO-World 开放词汇）

切到页面「全物体提取」模式后，用 119 类词表识别，不受 80 类限制。以 02 饭盒图为例（conf=0.15，实测）：

| 识别物品 | 分组 | 数量 | 最高置信度 |
| --- | --- | --- | --- |
| 面包 | 食物 | 4 | 0.38 |
| 柠檬（菠萝被近似） | 食物 | 3 | 0.24 |
| 碗 | 餐具 | 2 | 0.61 |
| 西兰花 | 食物 | 2 | 0.53 |
| 鸡蛋 | 食物 | 2 | 0.48 |
| 橙子 | 食物 | 2 | 0.27 |
| 盘子 | 餐具 | 2 | 0.57 |
| 牛肉 / 餐桌 / 热狗 | 食物/餐具 | 各 1 | 0.25~0.29 |

共 10 类 20 件——比垃圾分类模式的 3 类丰富得多。注意开放词汇是近似识别：菠萝被认成柠檬/橙子、肉丸被认成热狗或牛肉，属模型特性。

## 密集书本增强模式（切片推理）

`test_images/selected/09_密集书架_书本.png` 是书架截图，专门用来演示密集小目标。切换到页面「密集书本」模式后自动把阈值设为 0.15：整图用默认 0.25 阈值检测 0 本，密集模式检测到 87 本；把阈值调到 0.35 则剩 13 本，可现场展示"多召回"与"高置信"的取舍。画面只给分数最高的 12 个框写标签，框本身全部保留。

## 坚果识别模式（微调模型）

`selected/02_厨余_蔬菜食物.jpg` 左上粉色格里有 4 颗带壳杏仁。用「垃圾分类」「全物体提取」「密集书本」三种模式都认不出它们（词表里有 `nuts`，但开放词汇原型和带壳小目标形态不匹配，实测四档阈值全部 0 检出）。

切到页面「坚果识别」模式（conf=0.25）：**4 颗坚果全部检出，置信度 0.97 / 0.93 / 0.84 / 0.76，中文标签，无误检大框**。这个模式用的是人工标注微调的 `weights/yolov8n-nuts.pt`，链路见 `docs/WALKTHROUGH.md` Q12。

演示对比很直观：同一张饭盒图，先切「全物体提取」看坚果漏检 → 再切「坚果识别」看 4 颗全出来，用来讲"改词表/改阈值有天花板，训练才能把新类别教给模型"。

局限：只标了 1 张图，模型仅在高度相似场景可靠。要通用需补 30~50 张不同坚果照片，把框追加到 `datasets/nuts_real/annotations.json` 后重跑 `python scripts/train_nuts.py --epochs 40`。

## 演示建议组合

- **开场**：03 苹果 或 04 杯子——单一清晰，"框出来 + 给建议"一步讲清
- **进阶**：01 多物品混合——一张图讲清"多类分别投放"
- **对比**：07 人群 / 08 猫——强调"非垃圾对象不给建议"，体现检测与决策的分工
- **能力边界与训练**：02 饭盒图切「全物体提取」→「坚果识别」，讲清词表上限与训练闭环
