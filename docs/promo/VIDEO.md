## 1. 为什么这类片子有效（可复用表达）

1. **1 秒内给出具体任务，而不是软件名**。观众先看到"一张杂乱桌面照片"，再看到"框出来了"，理解成本接近零。
2. **证据出现在主张之后 2 秒内**。说"能识别"就立刻给真实检测框和置信度，不给空镜。
3. **数字承担叙事**。A/B 用真实实测的 `0 → 87 → 13 本`、`3 类 → 10 类 20 件`、`mAP@0.50 0.80` 三个数字推进，而不是堆功能列表。
4. **CTA 回答三问**：解决了什么、为什么值得试、如何开始；且多停留 2 秒。
5. **节奏**：平均 2.5–3 秒一个信息峰值，场景切换用遮罩/位移而非花哨转场，转场本身不抢信息。

## 4. 真实性边界（课程「最佳实践」对应项）

- **核心镜头全部使用真实素材**：`photo_*.jpg`（原图）、`detect_*.jpg`（Ultralytics 真实渲染）、`dashboard.png`（真实看板截图）、`training_curve.json`（真实训练日志）。
- **AI 生成只用于辅助画面**：网格、渐变、图标、遮罩等几何元素由 CSS 生成，不用于伪造检测框或结果图。
- **明确标注 demo 数据**：`outputs/results.json` 的 E1~E3 指标是教学示例值，本项目 README/看板已有「演示数据」标记；视频中凡出现该看板截图，同屏保留标注，A/B 主证据改用真实实测数据。
- **不复用他人素材**：参考片仅用于学习结构，成片不含参考片画面、音乐、人物形象。

## 6. 拿到参考片后补做实测拆解

```bash
# 环境：Python 3.10+ / ffmpeg；基础模式离线免费
git clone --depth 1 https://github.com/JuneYaooo/rea-video.git
# 按 README 安装 CLI 后：
rea-video prefs lang zh          # 中文报告
rea-video analyze /path/to/reference.mp4 --out ./breakdown/
# 产物：VIDEO.md（逐镜头时间码/分类/复刻提示）、report.html、字幕 SRT/ASS、节拍与 BPM
```

把实测 `VIDEO.md` 与本文件的镜头表逐行对照，只调整时长与转场，不改动「真实素材优先」与「CTA 三问」两条约束。

## 7. 成功判据

观众看完能回答三句话：**它解决了什么**（照片→检测框→投放建议，一条链路讲清）、**为什么值得试**（真实实测 A/B 与零依赖复现）、**如何开始**（一条命令 + 仓库地址）。若观众只记住「界面长什么样」，本片失败。
